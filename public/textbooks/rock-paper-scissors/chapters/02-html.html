Chapter 2 of 16

Write a page with HTML and CSS

Build one page a visitor could read: a heading, a sentence, a picture, a list, and a link. Put the colors in a second file.

A classmate should understand the event from the page alone.

Inputs
The event name, one sentence, three things to bring, one image file, and one outside address.
Expected output
A browser page with those parts, and colors that come from a stylesheet.
Rules
Use the tags below for the jobs they actually do. The image needs alternative text. The link needs an address.

What the tags do

Work in public/index.html unless a block says otherwise. If you do not want to type, use Copy, paste, save, and reload the browser. Each block is enough to test that one idea. The complete files are at the end if you want them in one paste.

Start the document

<!doctype html> is the first line. It tells the browser to use current HTML rules. It is not a pair. Paste it once, at the top.

First line of public/index.html
<!doctype html>

html wraps everything else. lang="en" says the words are English. head is information about the page, not the article. title is the text on the browser tab. body is what a person sees. Paste this under the doctype, save, and reload. The tab should say Campus game night, and the page should show the heading.

public/index.html · document shell
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Campus game night</title>
</head>
<body>
  <h1>Campus game night</h1>
</body>
</html>

meta charset tells the browser how letters and punctuation are stored. Leave it in head. Without it, an apostrophe or an accent can turn into the wrong character. viewport tells a phone to use the device width. Paste it under the charset line. On a narrow window the page should fit instead of looking like a tiny desktop page.

Inside head, under the charset line
<meta name="viewport" content="width=device-width, initial-scale=1">

The visible parts

h1 is the main heading. Use one on the page. The words go between the start tag and the end tag.

Inside body
<h1>Campus game night</h1>

p is a paragraph. Paste it under the heading. Reload. You should see a sentence under the heading, in a smaller size.

Under the h1
<p>One short game for people waiting between events.</p>

h2 is a heading under the main one. Paste it when a section needs its own title. Reload. It should be smaller than the h1 and larger than the paragraph.

Under the paragraph
<h2>Bring</h2>

ul is a list. Each li is one item. The items sit inside the list, not beside it. Paste this under the h2. Reload. You should see two bullets.

Under the paragraph
<ul>
  <li>A phone with a browser</li>
  <li>A few minutes</li>
</ul>

strong marks words that matter. It does not make a new paragraph. Paste this as another paragraph. The word “here” should look heavier than the rest of the sentence.

Another paragraph
<p>The rules page will live <strong>here</strong>.</p>

Links and images

a is a link. href is the address it opens. The words between the tags are what the person clicks. Paste this, reload, and click the words. The browser should leave your page. Use Back to return.

A link
<p><a href="https://firebase.google.com/docs/hosting">What web hosting is</a></p>

img is a picture. It does not wrap other content, so it has no end tag. src is the file, written relative to index.html. alt is the text if the picture cannot be seen. width is how wide to draw it, in pixels. Save the image file first, then paste the tag, then reload. You should see the picture. If you see a broken icon, the file name in src does not match the file next to index.html.

public/mark.svg · save this file, then use the img tag
<svg xmlns="http://www.w3.org/2000/svg" width="160" height="80" viewBox="0 0 160 80">
  <rect width="160" height="80" rx="8" fill="#2a211c"/>
  <text x="80" y="48" text-anchor="middle" fill="#ffb77d" font-family="Georgia, serif" font-size="28">RPS</text>
</svg>
Inside body, above the list
<img src="mark.svg" alt="The letters RPS on a dark card" width="160">

The stylesheet

link rel="stylesheet" in head loads style.css. Paste the link line into head, then save the CSS file. A CSS rule has a selector and declarations. body selects the body. color is the text color. background is the page color. font-family is the typeface. margin is space outside the element. max-width caps how wide it can grow. Reload. The page background should turn dark and the heading should be light.

Inside head
<link rel="stylesheet" href="style.css">
public/style.css · paste, save, reload
body {
  margin: 0;
  background: #1a1c1f;
  color: #f4efe8;
  font-family: Georgia, serif;
}

main {
  max-width: 36rem;
  margin: 2rem auto;
  padding: 1rem;
}

a {
  color: #ffb77d;
}

The a rule changes only links. After you reload, the hosting link should be a different color from the paragraph.

Or paste the whole page

If the pieces above are already in place, you can skip this. If you want one paste that includes every tag from this chapter, replace public/index.html and public/style.css with these files, save mark.svg, and reload.

public/index.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Campus game night</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main>
    <h1>Campus game night</h1>
    <p>One short game for people waiting between events.</p>
    <img src="mark.svg" alt="The letters RPS on a dark card" width="160">
    <h2>Bring</h2>
    <ul>
      <li>A phone with a browser</li>
      <li>A few minutes</li>
    </ul>
    <p>The rules page will live <strong>here</strong>. The link below leaves this page.</p>
    <p><a href="https://firebase.google.com/docs/hosting">What web hosting is</a></p>
  </main>
</body>
</html>
public/style.css
body {
  margin: 0;
  background: #1a1c1f;
  color: #f4efe8;
  font-family: Georgia, serif;
}

main {
  max-width: 36rem;
  margin: 2rem auto;
  padding: 1rem;
}

a {
  color: #ffb77d;
}
