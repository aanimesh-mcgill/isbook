Chapter 2 of 16

Write a page with HTML and CSS

Build one page a visitor could read: a heading, a sentence, a picture, a list, and a link. Put the colors in a second file.

A classmate should understand the event from the page alone.

Inputs
The event name, one sentence, three things to bring, one image file, and one outside address.
Expected output
A browser page with those parts, and colors that come from a stylesheet.
Rules
Use the tags below for the jobs they actually do. The image needs alternative text. The link needs an address.

What the tags do

The document

<!doctype html> tells the browser to use current HTML rules. html wraps the whole document. lang="en" says the language is English. head holds information about the page. title is the words on the browser tab. meta charset makes punctuation reliable. body holds what a person sees.

The visible parts

h1 is the main heading. Use one. p is a paragraph. ul is a list, and each li is one item. strong marks words that matter. A tag usually has a start and an end. The words between them are the contents.

Links and images

a is a link. href is the address it opens. The words between the start and end tags are what the person clicks. img is a picture and does not wrap other content, so it has no end tag. src is the image file, written relative to the HTML file. alt is the text if the image cannot be seen. width sets how wide it is drawn.

The stylesheet

link rel="stylesheet" in head loads style.css. A CSS rule has a selector and declarations. body selects the body. color is the text color. background is the page color. font-family is the typeface. margin is the outer gap.

public/index.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Campus game night</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main>
    <h1>Campus game night</h1>
    <p>One short game for people waiting between events.</p>
    <img src="mark.svg" alt="The letters RPS on a dark card" width="160">
    <h2>Bring</h2>
    <ul>
      <li>A phone with a browser</li>
      <li>A few minutes</li>
    </ul>
    <p>The rules page will live <strong>here</strong>. The link below leaves this page.</p>
    <p><a href="https://firebase.google.com/docs/hosting">What web hosting is</a></p>
  </main>
</body>
</html>
public/style.css
body {
  margin: 0;
  background: #1a1c1f;
  color: #f4efe8;
  font-family: Georgia, serif;
}

main {
  max-width: 36rem;
  margin: 2rem auto;
  padding: 1rem;
}

a {
  color: #ffb77d;
}
