Read the player's click

The page can state the rules. It cannot yet hear which move the player picked. That needs a script and a click.

The player needs proof the page noticed their move.

Inputs
A click on Rock, Paper, or Scissors.
Expected output
The status line names that move.
Rules
The button's visible label is for the player. data-move is the value the script reads. The script must not run before the buttons exist.

The ideas this feature needs

Add one piece, save, and reload. The complete files are after these tests.

A button the player can press

A button is a control. In the HTML crash course, a button appears and does nothing, because a click needs JavaScript. type="button" means it does not submit a form. data-move is the value the script will read. The words between the tags are the label the player sees. Paste this inside main, under the rules list. Reload. You should see three buttons. Clicking them does nothing until the script below is saved.

Inside main
<p>
  <button type="button" data-move="rock">Rock</button>
  <button type="button" data-move="paper">Paper</button>
  <button type="button" data-move="scissors">Scissors</button>
</p>
<p id="result">Choose a move.</p>

Load a script after the buttons exist

script src="script.js" defer loads the script and waits until the HTML has been read. Paste this in head. Then save public/script.js with the test below. Reload. The status line should say The script ran. If it still says Choose a move, the src does not match the file name, or the script tag is missing defer.

Inside head
<script src="script.js" defer></script>
public/script.js · first test
const result = document.querySelector("#result");
result.textContent = "The script ran.";

querySelector returns the first element that matches the selector. #result means the element whose id is result. textContent replaces the words in that element. It does not treat the words as HTML.

Hear the click

querySelectorAll returns every match. [data-move] means every element that has that attribute. addEventListener("click", ...) runs a function when that button is clicked. dataset.move reads data-move. Replace script.js with this, reload, and click Rock. The status line should say You chose rock.

public/script.js · click test
const result = document.querySelector("#result");

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    result.textContent = "You chose " + player + ".";
  });
}
