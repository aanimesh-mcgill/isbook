Read the player's click

The page can state the rules. It cannot yet hear which move the player picked. That needs a script and a click.

The player needs proof the page noticed their move.

Inputs
A click on Rock, Paper, or Scissors.
Expected output
The status line names that move.
Rules
The button's visible label is for the player. data-move is the value the script reads. The script must not run before the buttons exist.

The ideas this feature needs

A button is a control. type="button" means it does not submit a form. script src="script.js" defer loads the script and waits until the HTML has been read, so the buttons are findable. querySelector returns the first match. querySelectorAll returns every match. addEventListener("click", ...) runs a function when that button is clicked. dataset.move reads data-move. textContent replaces the words in an element and does not interpret them as HTML.

public/index.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Rock · Paper · Scissors</title>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>
<body>
  <main class="card">
    <h1>Rock · Paper · Scissors</h1>
    <p>Choose one move each round. Identical moves tie.</p>
    <ul>
      <li>Rock beats scissors.</li>
      <li>Paper beats rock.</li>
      <li>Scissors beats paper.</li>
    </ul>
    <p>
      <button type="button" data-move="rock">Rock</button>
      <button type="button" data-move="paper">Paper</button>
      <button type="button" data-move="scissors">Scissors</button>
    </p>
    <p id="result" role="status">Choose a move.</p>
  </main>
</body>
</html>
public/script.js
const result = document.querySelector("#result");

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    result.textContent = "You chose " + player + ".";
  });
}
