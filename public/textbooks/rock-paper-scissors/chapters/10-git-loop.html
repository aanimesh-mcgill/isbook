Change the project with Git

Every change from here to the end of the book uses the same loop. Git is how the project moves forward. Firebase is how a visitor sees the commit you decided to publish.

The loop

  1. Edit the files in public.
  2. Open index.html locally, or reload it, and check the behavior.
  3. Run git status and git diff. Read the lines.
  4. git add only the files that belong in this change.
  5. git commit with a sentence about the behavior, not a list of file names.
  6. git push.
  7. When the public link should match, firebase deploy --only hosting and open that link.
Terminal · after you have checked the page
git status
git diff
git add public/index.html
git commit -m "Rename the event heading"
git push
firebase deploy --only hosting --project YOUR_PROJECT_ID

Do it once on the heading

Change the h1 text to Campus game night if you already renamed it, or to Friday game night if you have not. Follow the loop. On GitHub, open public/index.html and confirm the new heading. Then reload the Hosting URL and confirm the same heading.

If git diff shows a change you did not mean, fix the file before you add it. A commit records what you staged, not what you hoped you staged.
