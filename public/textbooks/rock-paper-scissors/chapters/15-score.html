Keep score

A single round is decided and then forgotten. The page needs numbers that survive until the next click, and a way to set them back to zero.

The event needs a running score.

Inputs
Each result word, and a click on Reset score.
Expected output
Three totals, starting at zero, changing after each round, and returning to zero on reset.
Rules
A win adds one to the player. A loss adds one to the computer. A tie adds one to ties. Reset does not choose a move.

The ideas this feature needs

let creates a variable you can assign again. playerScore += 1 is a new value stored in the same variable. The variables live outside the click function, so the next click still sees them. A variable declared inside the click function would be thrown away when the click finished. renderScore writes the numbers into the page. The reset listener assigns 0 to each variable and writes the page again.

Paste the score markup under the status line. Paste the three let lines and renderScore at the top of script.js, outside the click handler. Inside the click handler, after you know the result word, paste the three if lines and the call to renderScore. Reload, click until you win, and the You total should become 1. Click Reset score. All three numbers should return to 0.

public/script.js · complete file
const moves = ["rock", "paper", "scissors"];
const result = document.querySelector("#result");
const score = document.querySelector("#score");
let playerScore = 0;
let computerScore = 0;
let ties = 0;

function chooseComputerMove() {
  const index = Math.floor(Math.random() * moves.length);
  return moves[index];
}

function decideWinner(player, computer) {
  if (player === computer) return "tie";
  if (player === "rock" && computer === "scissors") return "win";
  if (player === "paper" && computer === "rock") return "win";
  if (player === "scissors" && computer === "paper") return "win";
  return "lose";
}

function renderScore() {
  score.textContent = "You: " + playerScore + " · Computer: " + computerScore + " · Ties: " + ties;
}

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    const computer = chooseComputerMove();
    const outcome = decideWinner(player, computer);
    if (outcome === "win") playerScore += 1;
    else if (outcome === "lose") computerScore += 1;
    else ties += 1;
    result.textContent = "You chose " + player + ". Computer chose " + computer + ". Result: " + outcome + ".";
    renderScore();
  });
}

document.querySelector("#reset").addEventListener("click", () => {
  playerScore = 0;
  computerScore = 0;
  ties = 0;
  result.textContent = "Choose a move.";
  renderScore();
});
