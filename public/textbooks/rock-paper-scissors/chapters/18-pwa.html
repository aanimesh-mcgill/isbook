Let the game install and open offline

The single-page game already plays in the browser. A PWA adds a name, an icon, and a cache so the phone can open that same game with no signal.

A player who already visited can open the game offline.

Inputs
The SPA from the previous chapter, two PNG icons, and the HTTPS hosting URL.
Expected output
The browser offers to install the game. After one online visit, a reload with the network off still shows the buttons and accepts a move.
Rules
Cache the game's own files. Leave every other address to the network. Change the cache name when the files change.

What you are adding

A manifest is a small JSON file. It tells the browser the name, the icon, the start URL, and that the installed window should hide the browser chrome (display: standalone).

A service worker is a script the browser keeps after the tab closes. On the first visit it stores the files you list. On the next visit it can answer from that cache before the network does.

Use this for the finished game. The rules and the winner logic are already in the script. The phone does not need a server to pick rock, paper, or scissors.

Skip this while you are still saving a new version every few minutes. The cache will keep the old files until the cache name changes, and you will think the deploy failed. Skip it for a page whose words must come from a server at the moment someone opens it. Also skip it on a file:/// address. A service worker registers on HTTPS, or on localhost. Test it on the Hosting URL.

Name the app

Save two square PNGs beside index.html: icon-192.png and icon-512.png. Any picture you export at those sizes is enough. Then save the manifest and point the page at it.

public/manifest.webmanifest
{
  "name": "Campus game night",
  "short_name": "Game night",
  "start_url": "./",
  "display": "standalone",
  "background_color": "#141618",
  "theme_color": "#e77937",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
Inside head
<meta name="theme-color" content="#e77937">
<link rel="manifest" href="manifest.webmanifest">

Cache the game's files

Save this as public/sw.js. install stores the list. activate deletes caches from older names. fetch answers with the cache when the file is there, and with the network otherwise. A request to another site, such as a picture on a different host, is left alone.

public/sw.js
const CACHE = "campus-game-v1";
const FILES = [
  "./",
  "./index.html",
  "./style.css",
  "./script.js",
  "./manifest.webmanifest",
  "./icon-192.png",
  "./icon-512.png"
];

self.addEventListener("install", (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(FILES)));
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key)))
    )
  );
});

self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);
  if (url.origin !== location.origin) return;
  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request))
  );
});

Register it from the page. Paste this just before </body>.

Before the closing body tag
<script>
  if ("serviceWorker" in navigator) {
    navigator.serviceWorker.register("sw.js");
  }
</script>

Deploy, then open the Hosting URL. In Chrome, F12, Application, you should see the manifest and a service worker whose status becomes activated. The install icon in the address bar, or Install app in the menu, should offer to add it. Install it and open it from the home screen or the start menu. The window should show the game without the usual browser toolbar.

Visit once while online so the cache fills. Then in the Network tab choose Offline and reload. The buttons should still be there, and a click should still pick a winner. The score from before the reload is gone: it lived in memory, and the cache stores files, not the score.

When you change script.js or the CSS, change CACHE to campus-game-v2 before you deploy. The new name makes activate drop the old cache. Leave the name alone and the phone will keep playing the previous script.

Open the installable game. On this textbook's address the service worker belongs to the class site, so use your own Hosting URL to install your copy.
