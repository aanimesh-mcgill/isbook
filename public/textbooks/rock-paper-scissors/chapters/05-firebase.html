Learn what Firebase Hosting does

Firebase Hosting keeps a folder of files and answers browsers with those files over HTTPS. You do not write a server program for this page.

The accounts and tools

You need a Google account, a Firebase project that you create, and the Firebase command-line tools. The project has an ID. After a deploy, the site is at https://YOUR_PROJECT_ID.web.app unless you attach a different domain later.

What gets uploaded

firebase.json names the folder. Yours will say the public folder is public. A deploy uploads the files in that folder: the HTML, the CSS, and the image. It does not upload the editor, and it does not upload a password. Do not put a service-account file or an API secret in public. Anything in that folder can be downloaded by anyone with the link.

What you will refuse

When the setup command asks whether this is a single-page app, answer no. This site has a real index.html. A rewrite would send every address to one file and hide a missing page.

Create your own Firebase project for this exercise. Do not deploy it into a project that already hosts a class site.

firebase.json · sits next to public, not inside it
{
  "hosting": {
    "public": "public",
    "ignore": ["firebase.json", "**/.*", "**/node_modules/**"]
  }
}
