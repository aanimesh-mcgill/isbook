See why nobody else can open it

The page works for you. It does not work for anyone else.

Try to share the address

Copy the file:/// address and send it to another person, or open it on a phone that does not have this folder. It fails. That address points at a disk the other person does not have.

Why sending one file is not enough

If you email only index.html, the message does not include style.css or mark.svg. Their browser will show the words and a broken picture, without your colors. A page is a set of files that refer to each other by name.

A public page has an address that starts with https://. A server keeps the files and sends them to any browser that requests that address. Putting the files on a server is called hosting. The next two chapters do that with Firebase Hosting.
