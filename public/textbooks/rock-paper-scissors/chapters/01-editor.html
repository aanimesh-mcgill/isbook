Chapter 1 of 18

Download an editor

You need a program that shows the letters you type and saves them unchanged. A word processor will hide the tags and rewrite the file. Use a code editor.

Install Visual Studio Code

Download the editor for your computer from the official site. Install it with the default options. Open it once so you know it starts.

Make the project folder

Create a folder named campus-game. Inside it, create a folder named public. The page you publish will live in public. Keeping that name from the start means you will not have to move files when you host the site.

In Visual Studio Code, choose File → Open Folder and open campus-game, the outer folder. If the editor asks whether you trust the folder, trust it. You will only put files you typed in it.

Learn the parts you will actually use

The user interface guide names every region of the window. These six are the ones this book uses. With campus-game open, find each one before you write a page. Close the editor and open it again later: it returns to this folder and these files.

Editor

What it is. The large area where the letters you type appear.

When. Any time you change public/index.html or style.css.

Why. This is the only region that writes the file. A word processor would hide the tags. This area keeps them.

Explorer

What it is. The file list in the side bar. It is the campus-game folder on disk.

When. You create public, add index.html, or open a file you already saved. Right-click a file and choose Reveal in File Explorer (Reveal in Finder on a Mac) when you want the same file in the operating system.

Why. You can see whether the page sits in public or in the wrong folder. A single click opens a preview: the tab title is in italics, and the next single click reuses that tab. Double-click the file, or start typing, and the tab stays. Press Ctrl+B (Command+B on a Mac) if the list is hidden.

Activity bar

What it is. The column of icons at the far left. Each icon swaps the side bar.

When. Explorer for files. Search when you remember a heading and need the file that contains it. Source Control in chapters 8 and 9, when you commit. Extensions can wait.

Why. The file in the editor stays open while the side bar changes, so you can search or commit without losing your place.

Command Palette

What it is. A search box for every command in the editor. Open it with Ctrl+Shift+P (Shift+Command+P on a Mac).

When. You know the job and not the menu. Chapters 8 and 9 use it for Git: Rename Branch, Git: Create Branch, and Git: Clone. Ctrl+P (Command+P on a Mac) is the shorter box that opens a file by its name.

Why. One box reaches the command, so you do not have to hunt through menus for a name you have only heard once.

Status bar

What it is. The thin strip along the bottom.

When. After chapter 8 it shows the branch name, main or heading. It also shows the language of the open file and the line the cursor is on.

Why. A commit on the wrong branch records the change in the wrong history. The branch name is visible before you click the check mark.

Panel

What it is. The area under the editor. It holds the terminal, and also errors and warnings.

When. A later chapter tells you to run git or firebase. Open it with Ctrl+` (the key beside 1). On a Mac that shortcut is Control+`. You can also right-click the campus-game folder in Explorer and choose Open in Integrated Terminal.

Why. That terminal starts in the folder you opened, so the command runs on this project.

The editor saves files. The browser draws them. They are different programs. Saving in the editor does nothing visible until you open or reload the file in the browser.
