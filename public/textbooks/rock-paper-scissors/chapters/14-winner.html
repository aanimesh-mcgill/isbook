Decide who won

Both moves are on the page. The page still does not say who won. A function can compare the two names and return one word.

The player needs the result of the pair, not only the two names.

Inputs
The player's move and the computer's move.
Expected output
The status line ends with win, lose, or tie.
Rules
The same move ties. Rock beats scissors, paper beats rock, scissors beats paper. Anything else loses. The decision function does not change the page. The click handler does.

The ideas this feature needs

if runs a block when a condition is true. === asks whether two values are the same. A condition can use && to require both parts. The function returns "tie", "win", or "lose". Returning a word keeps the rules testable without looking at the screen.

Paste the function into script.js. Then, for one reload only, replace the status line inside the click handler with the test. Reload and click any button. The status line should say win, because rock beats scissors. Change the test to decideWinner("rock", "rock"), reload, and click again. It should say tie. Change it to decideWinner("rock", "paper"). It should say lose. Then use the complete file so the real moves are compared.

function decideWinner(player, computer) {
  if (player === computer) return "tie";
  if (player === "rock" && computer === "scissors") return "win";
  if (player === "paper" && computer === "rock") return "win";
  if (player === "scissors" && computer === "paper") return "win";
  return "lose";
}
public/script.js · complete file
const moves = ["rock", "paper", "scissors"];
const result = document.querySelector("#result");

function chooseComputerMove() {
  const index = Math.floor(Math.random() * moves.length);
  return moves[index];
}

function decideWinner(player, computer) {
  if (player === computer) return "tie";
  if (player === "rock" && computer === "scissors") return "win";
  if (player === "paper" && computer === "rock") return "win";
  if (player === "scissors" && computer === "paper") return "win";
  return "lose";
}

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    const computer = chooseComputerMove();
    const outcome = decideWinner(player, computer);
    result.textContent = "You chose " + player + ". Computer chose " + computer + ". Result: " + outcome + ".";
  });
}
