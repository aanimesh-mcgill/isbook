Meet the CSS requirements

The public page is readable. It is not yet a page you would leave up at a crowded event. Meet a written list of CSS requirements, deploy again, and look at the same link.

The page has to stay readable on a phone.

Inputs
The page you already hosted, and a window as narrow as 320 pixels.
Expected output
A centered card, light text on a dark page, an image that stays inside the card, and no sideways scrolling.
Rules
Do not remove the heading, list, image, or link. Change presentation in the stylesheet. Put class="card" on the main element.

What the new CSS is doing

A class selector starts with a dot. .card selects the element whose class is card. max-width stops the card growing wider than the text can stand. margin: 2rem auto puts space above the card and centers it, because auto shares the leftover width. padding is space inside the border. border-radius rounds the corners. img { max-width: 100%; height: auto; } lets the picture shrink with the card instead of forcing a sideways scroll.
