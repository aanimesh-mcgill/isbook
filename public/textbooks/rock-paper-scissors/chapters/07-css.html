Chapter 6 of 18

Meet the CSS requirements

The public page is readable. It is not yet a page you would leave up at a crowded event. Meet a written list of CSS requirements, deploy again, and look at the same link.

The page has to stay readable on a phone.

Inputs
The page you already hosted, and a window as narrow as 320 pixels.
Expected output
A centered card, light text on a dark page, an image that stays inside the card, and no sideways scrolling.
Rules
Do not remove the heading, list, image, or link. Change presentation in the stylesheet. Put class="card" on the main element.

What the new CSS is doing

Change the page one rule at a time. Paste a block into public/style.css, save, deploy or reload the local file, and check the result named under the block. The complete stylesheet is at the end.

A selector is the part of a rule that names which elements to paint. Paste one test at the bottom of public/style.css, save, and reload the page you already have open. Then delete that test before the next one. The .card rule is the one that stays.

A type selector names a tag

h2 matches every h2. body and a in your file are already type selectors. Paste this and reload. The word Bring turns orange. The main heading stays cream, because it is an h1.

Test, then delete
h2 {
  color: #e77937;
}

A class selects one kind of element

A class selector starts with a dot. .card selects the element whose class is card. A class is a label you can put on more than one element. Change the main start tag first. Then paste the rule. Reload. Only the main area should sit on a lighter panel. The rest of the page stays the darker body color. Leave this rule in the file.

public/index.html · the main start tag
<main class="card">
Add to public/style.css
.card {
  background: #1e2126;
  border: 1px solid #6b4d3c;
}

An id selects a single element

An id selector starts with #. An id has to be unique on the page, so #title can match only one element. Put id="title" on the h1. Paste the rule. The main heading turns tan. Bring stays cream. You can leave the id in the HTML. The card stays a class, because that label is a kind of box rather than the name of one heading.

The h1 start tag
<h1 id="title">Campus game night</h1>
Test, then delete
#title {
  color: #ffb77d;
}

The universal selector matches every element

* matches every element. An outline draws a line that does not move the text, so you can see each box. Paste this, reload, and look at the boxes around the heading, the picture, each list item, and the words strong and em wrap. Then delete the rule. A page of outlines is a test, not the event look.

Test, then delete
* {
  outline: 1px solid #e77937;
}

A comma groups selectors

h1, h2 is two selectors that share one rule. Both headings turn orange. A comma means or. Without the comma, h1 h2 would mean an h2 inside an h1, which this page does not have.

Test, then delete
h1, h2 {
  color: #e77937;
}

A space selects a descendant

main strong matches a strong anywhere inside main. On this page the word here sits inside a paragraph, and that paragraph sits inside main. The space still matches it. Paste the rule. The word here turns orange. The rest of the sentence stays cream.

Test, then delete
main strong {
  color: #e77937;
}

A child combinator stops at one level

main > p matches a paragraph that is a direct child of main. The > means the next level only. Each paragraph on this page is written directly inside main, so each one gets an orange bar. main > strong would match nothing here: the strong is inside the paragraph, so it is a grandchild of main. The descendant rule above is the one that reaches it.

Test, then delete
main > p {
  border-left: 3px solid #e77937;
  padding-left: 0.6rem;
}

A plus sign selects the next sibling

h1 + p matches the one paragraph that comes immediately after the h1. They have to share the same parent. Paste the rule. The first paragraph turns orange. The later paragraph, the one with the word here, stays cream.

Test, then delete
h1 + p {
  color: #e77937;
}

A tilde selects the later siblings

h1 ~ p matches every paragraph that follows the h1 and shares its parent. Other elements may sit between them. Both paragraphs turn orange. The link keeps the color from the a rule, because that rule paints the link text itself.

Test, then delete
h1 ~ p {
  color: #e77937;
}

Brackets select an attribute

a[target="_blank"] matches a link whose target is that value. The hosting link is the one that opens in a new tab, so it sits on a brown patch. These are the other shapes, and they work the same way:

  • a[target] matches a link that has the attribute, whatever the value.
  • a[href^="https"] matches an address that starts with https.
  • img[src$=".jpg"] matches a picture address that ends in .jpg.
  • img[alt*="flower"] matches an alt that contains flower.
Test, then delete
a[target="_blank"] {
  background: #3a2a22;
  padding: 0.15rem 0.4rem;
}

A pseudo-class selects a state or a position

A pseudo-class starts with one colon. It matches an element that is in a state, or that sits in a certain position, without an extra class in the HTML. li:first-child is the first child of its parent. Each list has its own first item, so the first bullet and the first numbered step turn orange. The second items stay cream.

Test, then delete
li:first-child {
  color: #e77937;
}

:hover matches the element while the pointer is on it. :focus matches the element you have reached with the keyboard. :last-child is the last child. :nth-child(2) is the second child. Paste the hover rule, reload, and move the pointer onto the hosting link. The link turns white and returns to tan when the pointer leaves.

Test, then delete
a:hover {
  color: #ffffff;
}

A pseudo-element selects a piece of an element

A pseudo-element starts with two colons. h1::first-letter styles the first letter of the heading. The C turns orange and grows. The rest of the words stay as they were. ::first-line is the first line. ::before and ::after insert an extra box before or after the element. This page does not need an inserted box.

Test, then delete
h1::first-letter {
  color: #e77937;
  font-size: 1.5em;
}

Delete the test rules. Keep .card. The next sections replace that rule with a longer one, and the finished stylesheet at the end of this chapter is the file to keep.

max-width and auto margins

max-width stops the card growing wider than the text can stand. margin: 2rem auto puts space above the card and centers it, because auto shares the leftover width. Paste this in place of the .card rule. Reload and widen the window. The panel should stay centered and stop growing.

Replace the .card rule
.card {
  max-width: 40rem;
  margin: 2rem auto;
  background: #1e2126;
  border: 1px solid #6b4d3c;
}

padding and rounded corners

padding is space inside the border. border-radius rounds the corners. Paste this in place of the .card rule. Reload. The heading should sit in from the border, and the corners should be curved.

Replace the .card rule
.card {
  max-width: 40rem;
  margin: 2rem auto;
  padding: 1.5rem;
  background: #1e2126;
  border: 1px solid #6b4d3c;
  border-radius: 12px;
}

Keep the picture inside the card

img { max-width: 100%; height: auto; } lets every picture shrink with the element that contains it. .card styles any element whose class is card. img styles every image, including images inside the card. These two rules set different properties on different elements, so the picture shrinks the same way if the img rule sits above .card or below it. Paste it anywhere in public/style.css. Narrow the window to about a phone width. The picture should shrink. The page should not grow a sideways scrollbar.

Order matters when two equally specific rules set the same property on the same element. A later img rule replaces an earlier one for the properties it names:

The second img rule wins
img {
  max-width: 100%;
}

img {
  max-width: 50%;
}

Both rules match every image. They are equally specific, and the second comes later, so the pictures stop at half the width of their container. Delete that pair after you have seen it, and keep a single img rule at 100%.

To style only the images inside a card, name that path. .card img is the descendant selector from earlier in this chapter: an img anywhere inside an element with class card. An image outside the card would keep its own size. On this page every picture is inside main, and main is the card, so img and .card img match the same pictures. The finished file uses img, which is enough while every picture lives in the card.

Only images inside the card
.card img {
  max-width: 100%;
  height: auto;
}
Add to public/style.css
img {
  max-width: 100%;
  height: auto;
}
