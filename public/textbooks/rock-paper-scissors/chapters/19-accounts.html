Save a public record and a private note

Requirements: A round shows itself as JSON text, and reading that text back names the outcome. On your own Firebase project, a round sends one Analytics event, a signed-in player gets a public win total, and a private note stays visible only to that player. Do not deploy this into the class project.

The last chapter could open the game with no network, and a reload still cleared the score. Those totals lived in variables. This chapter keeps two different copies in Cloud Firestore: a public board of names and win counts, and a private note plus the last move. Google Analytics counts how rounds end. It does not store the note.

An object, then JSON

The history list already stores each round as an object: a set of names and values. player, computer, and outcome are the names. round.outcome and round["outcome"] read the same value. When the variable name and the property name match, { player, computer, outcome } is the short way to write the object. The long way spells the names out, which is easier to check:

One round
const round = {
  player: player,
  computer: computer,
  outcome: outcome,
  wins: playerScore,
  losses: computerScore,
  ties: ties
};

JSON is that object written as text. Keys and strings use double quotes. Numbers stay numbers. JSON has no comments, no functions, and no single quotes. JSON.stringify(round, null, 2) makes the text, with line breaks. JSON.parse reads the text and returns an object again. Firestore stores the object. The box on the page shows the text, so you can see the shape before anything is saved.

Two scripts and one shared function

script.js is an ordinary script. account.js will be a module, loaded with type="module". A module keeps its variables private. The game cannot call a function declared inside the module. Assigning window.recordRound puts the function on the page's shared object, which both files can see. The click handler calls it after each round.

A module can await import("...") to load a library at that moment. This page waits until the config is a real web config, so the textbook copy still plays before you paste keys.

The web config object

Firebase gives you another object: the web configuration. In the Firebase console open Project settings, Your apps. Add a web app if the project does not have one, and enable Google Analytics for that project so the object includes measurementId. Copy the whole object into account.js in place of the placeholder below.

The apiKey in that object is an identifier for browser code. It is safe to commit account.js with that object in it. The lock is the Firestore rules later in this chapter, plus Authentication. The service-account JSON is a different file. That one is a server key. Do not download it into public/, and do not commit it.

Use your own project. The class site is not the place to create accounts or write documents.

Google Analytics

Analytics counts events. It is not the database, and it is not the score. logEvent sends a name and a small object of parameters. This game sends round_played and the outcome only. Do not send the email, the password, the private note, or the player's moves. Those are not counts.

The single-page game does not load a new document when you open Rules or Account, so a page view is a poor count of play. The custom event fires once per round, which is the count you want. In the Firebase console, Analytics, the event appears after a real visit to your Hosting URL. DebugView is faster than the main reports while you are testing.

If the config has no measurementId, sign-in can still work. The script leaves Analytics off when the browser cannot start it.

Sign in

In the console open Authentication, Sign-in method, and enable Email/Password. A password has to be at least 6 characters. Firebase keeps the password. Your script must not write it into Firestore, and it must not put it in an Analytics event.

createUserWithEmailAndPassword and signInWithEmailAndPassword return a promise: a result that arrives after the network answers. await pauses an async function until that result arrives. onAuthStateChanged runs when someone signs in or out and hands you the current user. user.uid is the id you will use as the document name. Sign out sets the user back to empty.

A public document and a private document

A collection is a set of documents. A document id plus its fields is an object. This game uses two collections.

  • profiles/{uid} is public. The fields are name, wins, losses, and ties. Anyone may read the board. Only a signed-in user may write the document whose id is their own uid.
  • private/{uid} is private. The fields are note and lastRound. lastRound is a nested object with the move names. Only that same uid may read or write it.

setDoc(..., { merge: true }) updates the fields you send and leaves the others in place. A round writes the public totals and the private last move. It does not send note, so a saved note stays. The Save private note button writes note and does not send the totals.

The score line on the Play view still starts at 0 after a reload. Those variables are memory. The public board is the saved copy, and it comes back only while the page is online and the rules allow the read.

Create the database from the Firestore page. Choose production mode. Production mode starts closed, which matches the rules you are about to deploy. Test mode leaves the database open for a limited time. Do not use test mode.

Save this as firestore.rules beside firebase.json, not inside public/.

firestore.rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /profiles/{uid} {
      allow read: if true;
      allow create, update: if request.auth != null
        && request.auth.uid == uid
        && request.resource.data.keys().hasOnly(["name", "wins", "losses", "ties"])
        && request.resource.data.name is string
        && request.resource.data.name.size() <= 40
        && request.resource.data.wins is number
        && request.resource.data.losses is number
        && request.resource.data.ties is number;
      allow delete: if false;
    }
    match /private/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

request.auth.uid == uid is the check that stops you writing profiles/someone-else. hasOnly stops a public document from growing an email or a note. The private match has no read: if true, so a classmate who can see the board still cannot open your note.

Add the firestore block to firebase.json. Keep the hosting block you already have.

firebase.json
{
  "hosting": {
    "public": "public",
    "ignore": ["firebase.json", "**/.*", "**/node_modules/**"]
  },
  "firestore": {
    "rules": "firestore.rules"
  }
}

Create public/account.js with this file. Replace firebaseConfig with the object from your project settings. Leave the placeholder in place until you are ready: the JSON box works either way, and the account buttons tell you the config is still missing.

public/account.js
const status = document.querySelector("#account-status");
const board = document.querySelector("#board");
const emailInput = document.querySelector("#email");
const passwordInput = document.querySelector("#password");
const nameInput = document.querySelector("#name");
const noteInput = document.querySelector("#note");

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT_ID.firebasestorage.app",
  appId: "YOUR_APP_ID",
  measurementId: "G-XXXXXXXX"
};

const ready = firebaseConfig.apiKey.startsWith("AIza");
const sdk = "https://www.gstatic.com/firebasejs/13.4.0/";
let auth = null;
let db = null;
let analytics = null;
let user = null;
let logEvent = null;
let setDoc = null;
let doc = null;
let stopNote = null;

window.recordRound = function (round) {
  if (analytics && logEvent) {
    logEvent(analytics, "round_played", { outcome: round.outcome });
  }
  if (!user || !db) return;
  setDoc(doc(db, "profiles", user.uid), {
    name: nameInput.value || "Player",
    wins: round.wins,
    losses: round.losses,
    ties: round.ties
  }, { merge: true });
  setDoc(doc(db, "private", user.uid), {
    lastRound: {
      player: round.player,
      computer: round.computer,
      outcome: round.outcome
    }
  }, { merge: true });
};

function needConfig() {
  status.textContent = "Paste your web app config in account.js, then deploy to your own project.";
}

document.querySelector("#create").addEventListener("click", async () => {
  if (!auth) return needConfig();
  const { createUserWithEmailAndPassword } = await import(sdk + "firebase-auth.js");
  try {
    await createUserWithEmailAndPassword(auth, emailInput.value, passwordInput.value);
  } catch (error) {
    status.textContent = error.message;
  }
});

document.querySelector("#signin").addEventListener("click", async () => {
  if (!auth) return needConfig();
  const { signInWithEmailAndPassword } = await import(sdk + "firebase-auth.js");
  try {
    await signInWithEmailAndPassword(auth, emailInput.value, passwordInput.value);
  } catch (error) {
    status.textContent = error.message;
  }
});

document.querySelector("#signout").addEventListener("click", async () => {
  if (!auth) return needConfig();
  const { signOut } = await import(sdk + "firebase-auth.js");
  await signOut(auth);
});

document.querySelector("#save-note").addEventListener("click", async () => {
  if (!user || !db) {
    status.textContent = "Sign in before saving a private note.";
    return;
  }
  await setDoc(doc(db, "private", user.uid), { note: noteInput.value }, { merge: true });
  status.textContent = "Private note saved.";
});

async function start() {
  if (!ready) {
    needConfig();
    return;
  }
  const { initializeApp } = await import(sdk + "firebase-app.js");
  const { getAuth, onAuthStateChanged } = await import(sdk + "firebase-auth.js");
  const firestore = await import(sdk + "firebase-firestore.js");
  const analyticsSdk = await import(sdk + "firebase-analytics.js");
  const app = initializeApp(firebaseConfig);
  auth = getAuth(app);
  db = firestore.getFirestore(app);
  setDoc = firestore.setDoc;
  doc = firestore.doc;
  try {
    if (await analyticsSdk.isSupported()) analytics = analyticsSdk.getAnalytics(app);
  } catch (error) {
    analytics = null;
  }
  logEvent = analyticsSdk.logEvent;
  firestore.onSnapshot(firestore.collection(db, "profiles"), (snap) => {
    board.innerHTML = "";
    snap.forEach((item) => {
      const data = item.data();
      const row = document.createElement("li");
      row.textContent = (data.name || "Player") + " · " + data.wins + " wins";
      board.append(row);
    });
  });
  onAuthStateChanged(auth, (next) => {
    user = next;
    if (stopNote) {
      stopNote();
      stopNote = null;
    }
    if (!user) {
      status.textContent = "Signed out.";
      noteInput.value = "";
      return;
    }
    status.textContent = "Signed in.";
    stopNote = firestore.onSnapshot(firestore.doc(db, "private", user.uid), (snap) => {
      if (snap.exists() && typeof snap.data().note === "string") {
        noteInput.value = snap.data().note;
      }
    });
  });
}

start();
