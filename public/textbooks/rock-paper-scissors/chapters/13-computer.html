Let the computer choose

The player can see their own move. The round still needs an opponent. A function can choose one of three names.

Each click needs a computer move as well as the player's move.

Inputs
The player's click, and a random choice among the three moves.
Expected output
The status line names both moves.
Rules
The computer chooses only rock, paper, or scissors. The choice is a function the click handler calls.

The ideas this feature needs

A function is a named block you can run again. return sends a value back to the line that called it. An array is an ordered list. The first index is 0. moves.length is 3. Math.random() returns a number from 0 up to, but not including, 1. Multiply by the length and Math.floor cuts off the fraction, leaving 0, 1, or 2.

Paste this function at the top of public/script.js, and paste the one test line where the click handler sets the status text. Save and reload several times. The status line should be rock, paper, or scissors, and it should not stay the same every time.

Add to public/script.js
const moves = ["rock", "paper", "scissors"];

function chooseComputerMove() {
  const index = Math.floor(Math.random() * moves.length);
  return moves[index];
}
Temporary test · replace the click handler body
result.textContent = chooseComputerMove();

When that changes on each reload, put the function call back inside the click handler so a click reports both names. The complete file is below.

public/script.js
const moves = ["rock", "paper", "scissors"];
const result = document.querySelector("#result");

function chooseComputerMove() {
  const index = Math.floor(Math.random() * moves.length);
  return moves[index];
}

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    const computer = chooseComputerMove();
    result.textContent = "You chose " + player + ". Computer chose " + computer + ".";
  });
}
