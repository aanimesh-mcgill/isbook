Show the recent rounds

The totals do not say what just happened. Keep the last five rounds on the page, newest first.

A player should see the recent pairs without a notebook.

Inputs
Each round's two moves and result, and the reset button.
Expected output
A list of at most five rounds, newest at the top. Reset clears it.
Rules
Build each list item in the script. Do not paste the player's text into the page as HTML.

The ideas this feature needs

An array can hold objects. Each object has player, computer, and outcome. unshift puts the new round at the front. pop removes the last item when the list is longer than five. for...of walks the array. createElement("li") makes a list item. textContent sets its words as text, so a move name cannot become a tag. append puts the item in the ol. Clearing innerHTML before the loop redraws the list from the array, which is the source of truth. Reset sets history.length = 0 and redraws.

Paste the heading and empty list under the reset button. Paste history and renderHistory into script.js. Inside the click handler, after the score updates, paste the three lines that record the round. Reload and click once. One numbered line should appear, with your move first. Click six times. The list should stay at five lines, and the newest round should be number 1. Click Reset score. The list should be empty.

public/script.js · complete file
const moves = ["rock", "paper", "scissors"];
const result = document.querySelector("#result");
const score = document.querySelector("#score");
const historyList = document.querySelector("#history");
let playerScore = 0;
let computerScore = 0;
let ties = 0;
const history = [];

function chooseComputerMove() {
  const index = Math.floor(Math.random() * moves.length);
  return moves[index];
}

function decideWinner(player, computer) {
  if (player === computer) return "tie";
  if (player === "rock" && computer === "scissors") return "win";
  if (player === "paper" && computer === "rock") return "win";
  if (player === "scissors" && computer === "paper") return "win";
  return "lose";
}

function renderScore() {
  score.textContent = "You: " + playerScore + " · Computer: " + computerScore + " · Ties: " + ties;
}

function renderHistory() {
  historyList.innerHTML = "";
  for (const round of history) {
    const item = document.createElement("li");
    item.textContent = round.player + " vs. " + round.computer + " · " + round.outcome;
    historyList.append(item);
  }
}

for (const button of document.querySelectorAll("[data-move]")) {
  button.addEventListener("click", () => {
    const player = button.dataset.move;
    const computer = chooseComputerMove();
    const outcome = decideWinner(player, computer);
    if (outcome === "win") playerScore += 1;
    else if (outcome === "lose") computerScore += 1;
    else ties += 1;
    history.unshift({ player, computer, outcome });
    if (history.length > 5) history.pop();
    result.textContent = "You chose " + player + ". Computer chose " + computer + ". Result: " + outcome + ".";
    renderScore();
    renderHistory();
  });
}

document.querySelector("#reset").addEventListener("click", () => {
  playerScore = 0;
  computerScore = 0;
  ties = 0;
  history.length = 0;
  result.textContent = "Choose a move.";
  renderScore();
  renderHistory();
});
