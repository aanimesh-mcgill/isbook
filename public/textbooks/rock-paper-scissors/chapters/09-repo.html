Create the repository

Install Git, create the accounts, and put this project in a GitHub repository. The files you push should be the styled page you can already open on your Hosting URL.

Install and identify yourself

Install Git. Create a GitHub account if you do not have one. You already have the Google account you used for Firebase. Tell Git the name and email to write into each commit. Use the email on your GitHub account.

Terminal
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Start the repository

In campus-game, start Git and look at the status. Create .gitignore before the first commit so tool files never enter the history.

.gitignore
node_modules/
.firebase/
firebase-debug.log*
*.log
Terminal · in campus-game
git init
git status
git add .
git status
git commit -m "Host the styled campus page"

git status before git add should list your page, stylesheet, image, and firebase.json. It should not list a password. The second status should show those files staged.

Create the empty GitHub repository

On GitHub, create a new repository named campus-game. Leave it empty: no README, no license, and no generated gitignore. You already have the history locally. Copy the HTTPS address GitHub shows.

Terminal · use your repository address
git remote add origin https://github.com/YOUR_NAME/campus-game.git
git branch -M main
git push -u origin main

If Git asks you to sign in, use the browser prompt. Do not paste a token into a file in the project. Refresh the GitHub page. You should see public/index.html, public/style.css, public/mark.svg, and firebase.json.
