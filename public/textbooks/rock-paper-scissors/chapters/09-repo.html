Create the repository

Install Git, create the accounts, and put this project in a GitHub repository. The files you push should be the styled page you can already open on your Hosting URL.

Install and identify yourself

Install Git from the official site. Visual Studio Code does not include Git. It calls the Git you install. Create a GitHub account if you do not have one. You already have the Google account you used for Firebase. Tell Git the name and email to write into each commit. Use the email on your GitHub account. That name is the author written into history. It is not your password.

Terminal
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Initialize the folder

Open campus-game with File → Open Folder. Create .gitignore first, so tool files never enter the history. Then open Source Control. The shortcut is Ctrl+Shift+G on Windows and Linux, and Control+Shift+G on a Mac. Click Initialize Repository.

The status bar at the bottom left should say main. That is the branch name. To see how a rename works, open the Command Palette with Ctrl+Shift+P (Shift+Command+P on a Mac), run Git: Rename Branch, type test, and press Enter. The status bar should say test. Rename it back to main the same way. Leave it on main.

Each new file is marked U, for untracked. Git can see it and has never saved it. Click the + beside index.html. The letter should change to A, for added, and the file should move under Staged Changes. Click the + on the Changes heading to stage the rest of the project files in one step. Do not stage a password or a token. If one is listed, leave it unstaged and delete it from the folder.

Type this message in the box at the top of Source Control, then click the check mark:

Commit message
Host the styled campus page

The message describes the change. It is for the next person who reads the history, including you. After the check mark, those files should leave the Changes list. The commit is on this computer. GitHub does not have it yet. Open the Terminal in the editor and run git log --oneline. You should see that message as the latest line.

The same steps as commands, if you would rather paste them:

.gitignore
node_modules/
.firebase/
firebase-debug.log*
*.log
Terminal · in campus-game
git init
git status
git add .
git status
git commit -m "Host the styled campus page"

git status before git add should list your page, stylesheet, image, and firebase.json. It should not list a password. The second status should show those files staged.

Publish the branch

In Source Control, click Publish Branch. Allow the GitHub sign-in. Choose a public repository when it asks. When publishing finishes, open the repository in the browser. You should see public/index.html, public/style.css, public/mark.svg, and firebase.json.

Use the browser prompt to sign in. Do not paste a token into a file in the project. Do this once. If you also run the commands below, you will be trying to add a second remote.

The same publish from the terminal, if Publish Branch is not available. Create an empty repository on GitHub named campus-game: no README, no license, and no generated gitignore. Copy the HTTPS address.

Terminal · use your repository address
git remote add origin https://github.com/YOUR_NAME/campus-game.git
git branch -M main
git push -u origin main

git branch -M main is the rename you already did in the status bar. -u remembers that main on this computer tracks main on GitHub, so later a plain git push knows where to go.
