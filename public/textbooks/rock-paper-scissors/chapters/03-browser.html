Open the page in the browser

You opened index.html in chapter 2 and reloaded it after each paste. The page is still not on the web. Read the address in that tab.

Read the address

The address starts with file:///. The browser is reading a file on this computer. It is not asking another computer for the page. Reload the tab after every save. A tab you do not reload still shows the previous save.

If that tab is closed, right-click index.html in Explorer, reveal it in the file manager, and double-click it. You can also drag the file into Chrome or Edge. Save style.css and mark.svg beside it before you check the pieces below.

Check the pieces

You should see the heading, the sentence, the picture, three list items, and a link. Click the link. It should leave your page and open the hosting documentation. Use the Back button to return.

If the picture is broken, src does not match the file sitting next to index.html. If the page is black text on white, style.css did not load. Check the link href and the file name.
