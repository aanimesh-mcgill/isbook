Open the page in the browser

The page is not on the web yet. Open the file you saved and read the address.

Open the file

Save index.html, style.css, and mark.svg. In the editor, right-click index.html and reveal it in the file manager, then double-click it. You can also drag that file into Chrome or Edge.

Read the address

The address starts with file:///. The browser is reading a file on this computer. It is not asking another computer for the page. Reload the tab after every save. If you do not reload, you are looking at the previous save.

Check the pieces

You should see the heading, the sentence, the picture, three list items, and a link. Click the link. It should leave your page and open the hosting documentation. Use the Back button to return.

If the picture is broken, src does not match the file sitting next to index.html. If the page is black text on white, style.css did not load. Check the link href and the file name.
