Learn the Web by Building Rock–Paper–Scissors

Start with a page only you can open. Host it so someone else can. Keep every later change in Git. Then teach the page to play, one feature at a time.

How the book is ordered

Chapters 1–2 get an editor, a real HTML page, a stylesheet, and the file open in a browser. Chapter 3 reads that file address, then explains the client, the server, the URL, and the request and response that make a public page. Chapters 4–5 put the page on Firebase Hosting. You test the public link. Chapter 6 adds the CSS the event needs, and you deploy again.

Chapters 7–9 are Git and GitHub. You install Git, create the accounts, make a repository for this project, and use that repository for every change after that. Chapters 10–15 turn the hosted page into the game. Each chapter adds one feature and the JavaScript that feature needs, then commits and deploys.

Each chapter is its own file in chapters/. The runnable checkpoints are in versions/. This book is already in the class Git repository, so a change to one chapter is a change Git can show on its own.
