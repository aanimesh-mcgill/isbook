Run a campus game-night release

Exercise solution

Use playerScore + computerScore + ties as the total. Append it to the template in renderScore and start the HTML at zero. Sample handoff: “Added a rounds-played total. The rule suite passed. Six moves showed six rounds and five history rows. Reset and the next move showed one round and one row. Preview: [URL]. Commit: [hash]. Review: [name]. Scores are per tab.”

Debugging solution

The code is using history.length, which is capped at five. Use the sum of the three counters, then verify six rounds and reset.
