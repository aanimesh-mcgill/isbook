Turn the game rules into a decision

Exercise solution

decideWinner("rock", "scissors")  // win
decideWinner("paper", "rock")  // win
decideWinner("scissors", "paper")  // win
decideWinner("scissors", "rock")  // lose
decideWinner("rock", "paper")  // lose
decideWinner("paper", "scissors")  // lose

Debugging solution

Use decideWinner(player, computer). The first argument is always the player. Testing only ties would miss the mistake.
