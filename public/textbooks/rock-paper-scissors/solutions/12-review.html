Combine changes through a pull request

Exercise solution

Create labels with git switch -c label-a and commit “Start over”. Return to main, create label-b, and commit “Clear scores”. Run git merge label-a on label-b. Edit public/index.html to keep the agreed label with id="reset", remove <<<<<<<, =======, and >>>>>>> lines, stage the file, and complete the merge with git commit. Play a round and reset.

Debugging solution

Read the merged HTML and script together. Align their ID and selector, then check resets after several rounds and after an empty session. A clean merge reports that Git combined text successfully.
