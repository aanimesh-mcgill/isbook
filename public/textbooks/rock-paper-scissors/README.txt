LEARN THE WEB BY BUILDING ROCK–PAPER–SCISSORS

Extract the entire ZIP. Open RPS_Textbook/index.html in a current browser.
Use the chapter list or Next and Previous links. Quizzes provide feedback
after each choice. Mark completed practice sets when ready. Progress is
stored in the current browser when it allows local storage for files.

index.html       Interactive textbook and embedded final game
assets/          Local textbook stylesheet and script
versions/        Seven complete snapshots. Each has its own index.html.
exercises/       Printable coding and debugging tasks
solutions/       Worked answers and diagnosis
rps-git-lab/     Final project for Git, testing, and Firebase Hosting

Use an editor and browser for Chapters 1–8. The local server lab uses
Python 3. Git labs use Git and optionally a GitHub account. Automated tests
use Node.js 22 or newer. Firebase labs use the Firebase CLI and, for cloud
preview or release, an authorized Firebase project. Official setup links
are included in the relevant chapters. The ZIP works without a CDN.

Make your own practice copy before editing. Keep the folder structure intact.
